How each number is derived
Cash units = (cash + spend-as-cash) × cash multiplier. Sweat units = max(0, market salary − drawn salary) × months × (commitment % / 100) × sweat multiplier. IP units = IP value × IP multiplier, only when IP is set to count as equity. Base % = a founder’s (cash + sweat + IP) units ÷ everyone’s. Points % = a founder’s (idea + role + network + risk) ÷ everyone’s. Final founder % = (1 − influence) × Base % + influence × Points %. Cap-table % = Final founder % × (100 − ESOP %). The ESOP pool takes the remainder.

Profit sharing

A one-period waterfall: set aside money to reinvest, repay any founder money that was booked as repayable, then divide what’s left. Monthly founder salaries are an operating cost and sit outside this.

Custom profit-sharing ratio (need not match equity — common in partnership firms). Values are normalised to 100%.
